# UNIFAID — Web Summit Speaker Brief

## One-line description
UNIFAID is an open, provider-neutral communication protocol and prototype that lets people route a shared conversation to multiple AI systems while retaining choice, attribution and portable history.

## 30-second pitch
Today, AI conversations are trapped in separate platforms. UNIFAID is building an open communication layer so people can choose which AI providers participate in one shared conversation, compare their responses and carry their history in an open format. We are starting with a working demonstrator and inviting the ecosystem to help define the protocol, security model and governance in public.

## What to demonstrate (90 seconds)
1. Open the local prototype.
2. Select two or more providers.
3. Explain the consent control and that selected providers receive the shared context.
4. Send one prompt.
5. Show separately attributed responses and any provider errors.
6. Export the conversation JSON.
7. State clearly whether the screen is in mock mode or using configured live API credentials.

## The ask
- AI providers: publish stable, documented interoperability interfaces and help test adapters.
- Developers: build connectors, clients and conformance tests.
- Security researchers: challenge the threat model and privacy claims.
- Universities and civil society: help develop governance and public-interest safeguards.
- Investors and ecosystem partners: support an open infrastructure project without demanding protocol capture.

## Proof points to state accurately
- Public protocol draft and charter are in the GitHub repository.
- Prototype 0.1 supports a local shared-prompt demonstrator, mock mode, provider selection, attribution and JSON export.
- Live provider calls require the user's own API keys and may incur charges.
- Federation, production-grade security, multi-user rooms and a hosted service are not implemented yet.

## Suggested closing line
**“Let's make AI interoperability a public good — open enough to connect the world, and responsible enough to deserve its trust.”**
